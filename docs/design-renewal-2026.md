# デザイン刷新プロジェクト (2026)

ブランチ: `feature/renew-desgin-2026`

## 目的・ゴール

豆蔵デベロッパーサイト（2021/11開設、2026年で5周年）のUIを刷新し、「豆蔵の技術サイトを、次のステージへ進化させる」。デベロッパーサイトサークルの活動の一環として、メンバーの実践的なスキルアップも兼ねる。

- **Must**: 2026年度中にUIを変更し、本番リリースする
- **Better**: UIに関連する改修・改善、新しいバックエンドシステムの検討・構築

## 対象範囲

- 対象: サイト全体のUI/UX（レイアウト、スタイル、コンポーネント）
- 記事コンテンツ（`src/posts/` 配下）も対象（記事ページの表示・レイアウトを含む）
- 新バックエンドシステムはBetter項目であり、UI刷新の後（2027年3月以降）に検討する

## 現状の方針・決定事項

- 外部のデザイン会社・デザイナーと協働してデザイン案を確定し、フロントエンドを実装する
- プレビュー環境で実装・テストしてから本番ローンチする
- 活動は業務時間外の無理のない範囲で行う
- 進め方（予定）
  1. 2026年9〜10月: 現行サイトの構造把握、プレビュー環境の構築、課題収集と方針策定
  2. 2026年11月〜2027年2月: デザイン案の確定、新UIの実装、プレビュー環境でのテスト、本番ローンチ
  3. 2027年3月以降: バックエンド拡張、運用の自律分散化
- 技術スタック: TypeScript / Deno / Lume / GitHub Actions（Netlifyでデプロイ）
- 活動管理はGitHub Projectで行う
